A month dropdown in the wrong language.

While rebuilding my booking product on coss ui, I noticed its Calendar ignored the locale it was given in one place: the month dropdown.

Noticed

The date library passes every formatter the calendar's locale. The month formatter dropped it and used the machine's language instead.

Why it matters

Booking pages are read in many languages. A server and a browser in different locales could also render different labels, which React reports as a hydration mismatch.

The fix

Use the formatter the library already hands over. One line, with the same short month in English.

// registry/default/ui/calendar.tsx
- formatMonthDropdown: (date: Date) =>
-   date.toLocaleString("default", { month: "short" }),
+ formatMonthDropdown: (month: Date, dateLib: DateLib) =>
+   dateLib.format(month, "LLL"),

Reviewed and merged by coss ui's maintainer the same day.
