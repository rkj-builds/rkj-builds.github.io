Helix · Travelopia, ten travel brands

Ten brand designers stopped handing over pictures and started merging code

Helix is where each Travelopia brand's design system lives as working code. The growth here is the team's: more designers shipping, sooner, for less.

The problem

Every design was a picture, and the build drifted from it

A designer drew a screen and handed it over. Even a comment on a preview needed a paid seat, so feedback came back as email.

$205a seat, per reviewer, just to leave a comment on a preview.
What we tried first

AI tools made screens fast, but not in the brand's code

v0, Lovable and Figma Make each stopped short of the brand's own components.

v0Writes React in its own components, not the brand's.
LovableA whole app from a prompt, with none of the brand's system in it.
Figma MakePrototypes from the design, but redrawn, so the build starts again.
HelixThe brand's design, its code and its rules in one place.
Getting started

A first merged page in under an hour

Seven steps from access to a merged exploration. The first command is a skill that does the setup.

Get started: progress is saved as you go.
The system

A new brand is an install, not a project

Colour, type and spacing are read from the brand's stylesheet on every load, so the page can't drift from the code.

The design-system page has no content of its own. All of it comes from the brand's code.
Explorations

Variants are compared on the real page

Every exploration lives on main as working code, with a stable link. The one that wins is promoted into components.

Explorations across brands, each a folder of variants.
Reviews

A comment went from $205 a seat to nothing

Comments are pinned to the element, with one sign-in on a work address. Feedback arrives on the page, not by email.

A review on a live exploration: variants on the left, details and annotations on the right.
Iterations

In nearly every review, someone asked about the phone

So the preview opens desktop and phone together, kept on the same content as you scroll.

Both widths at once, scroll kept in step.

More designers shipping code, sooner, for less
