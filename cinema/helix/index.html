Overview

How might we let the one designer at each brand ship real pages, without an engineer rebuilding them?

Context

Travelopia is a group of travel brands: yacht charters, canal holidays, adventure trips. Each has its own website, and almost every brand has one designer. Each kept its design system somewhere different, and nobody had time to keep it in step with the code.

Problem

A design was a picture, and the build drifted from it

A designer drew a screen and handed it to an engineer, and the build slowly moved away from the picture. Even reviewing cost money: leaving a comment on a preview needed a paid seat, $205 each, so feedback came back as email.

What we tried first

The AI tools made screens fast, but not the brand's code

  • v0Writes React in its own components, not the brand's.
  • LovableA whole app from a prompt, with none of the brand's system in it.
  • Figma MakePrototypes from the design, but redrawn, so the build still starts again.
  • HelixThe brand's design, its code and written rules in one place, so whatever gets made comes out consistent, and for a reason.
Solution

The brand's design system, its code and its rules, in one workspace

  • Reads the brand's codeColour, type and spacing come from the brand's stylesheet on every load, so the page can't say anything the code doesn't. A new brand is an install.
  • First merge, under an hourA Get started page of seven steps; the first command is a skill that does the setup.
  • Rules that load in timeFourteen skills for Claude Code and OpenCode. The design audit and the accessibility check load with every build.
  • Tools on the real pageTen tools in one dock. Inspect names a component and its tokens; Annotate turns notes on elements into one prompt for the agent.
  • Comments, in-housePinned to the element, one sign-in with a work address. The $205 seat became nothing.
Iterations

Four times the data said otherwise

  • Accent at 3.4:1The first accent failed contrast. It was replaced, not shipped; every accent is now a pair that passes on every surface.
  • The phone questionIn nearly every review, four minutes in, someone asked about the phone. So the preview opens desktop and phone together, scroll kept in step.
  • About fifty lost commentsA guessed project name fell through to a default. Now nothing is guessed: the name is set once.
  • The slow checkThe accessibility check was switched off once for being slow. I made it fast instead of lowering the bar.
Teamwork

Ten brand teams, one workspace each

Nine brands have built their design systems in it and eight run comments. Anyone can add a tool: a skill scaffolds it, checks it against the toolbar's rules and opens the pull request, so the tenth tool cost an afternoon.
