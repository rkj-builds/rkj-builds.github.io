# rkj-builds.github.io

Rahul Jha's personal site: plain HTML and one stylesheet, no build step.

- `index.html`: home (selected work, experience, contribution grid)
- `resume.html`: résumé; prints to one page (browser print to PDF)
- `work/`: small write-ups
- `data/contributions.json`: refreshed daily by `.github/workflows/contributions.yml` from GitHub's public contribution calendar. Private contributions show only if "Include private contributions" is on in profile settings.
